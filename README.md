# LEARNVERSE

LEARNVERSE 是一个 Windows 本地运行的沉浸式学习站。首页采用左侧标题、右侧星球、悬浮导航和底部学习面板。学习界面以简体中文为主，英文用于品牌、首页标题和官方课程名称。

## 本地运行

使用 Node.js 22.12 或更新的受支持版本。当前项目在 Node.js 24 上验证。

```powershell
npm.cmd ci
npm.cmd run dev
```

打开终端输出的本地地址，默认是 [http://127.0.0.1:5173](http://127.0.0.1:5173)。从首页进入学院，选择课程后点击「开始学习」。课程、章节、练习与解析均在站内，页面和本地进度无需账号。

```powershell
npm.cmd run build
npm.cmd run preview
```

构建输出在 `dist`。生产预览默认地址是 [http://127.0.0.1:4173](http://127.0.0.1:4173)。本地开发和预览服务器都支持直接打开页面路由。

## 代码实验室

从「实验室」选择语言自由练习，或在任一章节的「动手练习」直接修改起始代码。按「运行代码」查看输出，有行号的错误与警告可以点回源代码。提供预期输出的题目会对比本次结果。想核对思路时，再展开编辑器下方的参考解法。

| 内容 | 需要的环境 |
| --- | --- |
| Python、JavaScript、SQL | 手机或电脑浏览器即可运行。本地站点按需加载运行环境，Python 首次加载约 13.5 MB 未压缩。 |
| HTML、CSS | 浏览器内预览布局，表单可以填写。预览不执行页面脚本、不提交表单。章节中的交互规则另有可运行的 JavaScript 练习。 |
| C、Java | Windows 电脑，从项目目录双击 `安装并启动实验室.cmd`。脚本检查 Node.js 22.12+、GCC 和 Java JDK，只用 WinGet 与 MSYS2 补装缺少的工具。预览地址为 [本机实验室](http://127.0.0.1:5174/lab)。 |

本机模式可以编译单文件 C17 程序和带 `main` 的单文件 Java 程序。请只运行自己写的或信任的代码，编译和执行使用当前 Windows 帐号。运行服务只监听 `127.0.0.1`，不提供给手机、局域网或公网。给同学分享时，只发布 `dist` 静态站点即可。代码草稿与进度保存在各自当前浏览器和网址下。

## 页面和数据

| 页面 | 功能 |
| --- | --- |
| Universe | 可重播和跳过的开场、星球主视觉、学习路线入口、精选领域与资源 |
| Explore | 八个知识领域、先修知识、推荐路线、课程与资源 |
| Academy | 筛选站内课程，阅读零基础术语讲解、在章节内写代码并完成练习 |
| Library | 中英文官方学习资源、搜索和筛选、收藏、来源和许可证 |
| Lab | 多语言代码编辑与运行、算法分步演示、知识测试与项目挑战 |
| My Universe | 本地学习记录、正在学习的课程、路线、收藏、技能树与成就 |

个人数据存储在当前浏览器和站点地址下。切换浏览器、端口或设备会使用另一个本地存储。学习时间可在个人中心手动记录。章节测验全部答对后记录章节完成，全部章节完成后记录课程完成。「继续学习」打开最近访问的章节。代码练习的结果单独显示，可反复运行。

## 工程结构

- `src/components` 存放主题选择器、开场和按需加载的 Three.js 场景。
- `src/pages` 存放六个页面及各自样式。
- `src/data` 存放站内课程、第三方资源、领域和学习路线。`src/data/expansions` 按课程与章节 ID 组织详解、易错点、动手题和判分题，只在打开学习工作区后加载。改编课程还需填写 `attribution`，并随构建提供许可文本。
- `src/state` 管理进度和收藏的本地持久化。
- `public/art` 存放原创星球与山谷素材。

使用 React、TypeScript、Vite、React Router、Three.js、Lucide 和本地 Geist 字体。窄屏、不支持 WebGL 2 的环境使用 CSS 轨道和静态星球。在系统开启减少动态效果时，开场使用简短的静态画面。

## 验证

```powershell
npm.cmd test
```

浏览器测试可使用已安装的 Microsoft Edge，也可先用 `npx.cmd playwright install chromium` 安装测试浏览器。测试自动在 4176 端口启动本地服务器。

学院提供 11 门中文课程、46 章、46 道带参考解法的动手题与 184 道带解析的判分题。每章有学习目标、目录、示例和常见易错点。Python 官方教程进阶练习与 ROS 2 通信基础基于有署名的节选改编，并附有站内详解。二分查找、Python range 和 ROS 2 话题各有可操作演示。第三方完整课程继续作为选读资源，旧的学习记录仍可查看。学习资源详见 [RESOURCE_SOURCES.md](./RESOURCE_SOURCES.md)，许可详见 [THIRD_PARTY_LICENSES.md](./THIRD_PARTY_LICENSES.md)。
